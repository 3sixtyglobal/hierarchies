# Function: hierarchiesPropertiesGet()

> **hierarchiesPropertiesGet**(`httpRequestContext`, `componentName`, `request`): `Promise`\<`IHierarchiesPropertiesGetResponse`\>

Handles a request to get all properties from a federation.

## Parameters

### httpRequestContext

`IHttpRequestContext`

The request context for the API.

### componentName

`string`

The name of the component to use in the routes.

### request

`IHierarchiesPropertiesGetRequest`

The request object.

## Returns

`Promise`\<`IHierarchiesPropertiesGetResponse`\>

The response object with the properties in the body.
