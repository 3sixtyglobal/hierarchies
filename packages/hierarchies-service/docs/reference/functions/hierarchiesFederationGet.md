# Function: hierarchiesFederationGet()

> **hierarchiesFederationGet**(`httpRequestContext`, `componentName`, `request`): `Promise`\<`IHierarchiesFederationGetResponse`\>

Handles a request to get a federation by its ID.

## Parameters

### httpRequestContext

`IHttpRequestContext`

The request context for the API.

### componentName

`string`

The name of the component to use in the routes.

### request

`IHierarchiesFederationGetRequest`

The request object.

## Returns

`Promise`\<`IHierarchiesFederationGetResponse`\>

The response object with the federation in the body.
