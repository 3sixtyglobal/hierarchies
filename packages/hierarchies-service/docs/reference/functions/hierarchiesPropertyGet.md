# Function: hierarchiesPropertyGet()

> **hierarchiesPropertyGet**(`httpRequestContext`, `componentName`, `request`): `Promise`\<`IHierarchiesPropertyGetResponse`\>

Handles a request to get a property from a federation.

## Parameters

### httpRequestContext

`IHttpRequestContext`

The request context for the API.

### componentName

`string`

The name of the component to use in the routes.

### request

`IHierarchiesPropertyGetRequest`

The request object.

## Returns

`Promise`\<`IHierarchiesPropertyGetResponse`\>

The response object with the property in the body.
