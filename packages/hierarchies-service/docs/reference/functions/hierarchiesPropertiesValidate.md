# Function: hierarchiesPropertiesValidate()

> **hierarchiesPropertiesValidate**(`httpRequestContext`, `componentName`, `request`): `Promise`\<`IHierarchiesPropertiesValidateResponse`\>

Handles a request to validate multiple properties for a federation.

## Parameters

### httpRequestContext

`IHttpRequestContext`

The request context for the API.

### componentName

`string`

The name of the component to use in the routes.

### request

`IHierarchiesPropertiesValidateRequest`

The request object.

## Returns

`Promise`\<`IHierarchiesPropertiesValidateResponse`\>

The response object with the validation result in the body.
