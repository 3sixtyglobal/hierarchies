# Variable: PropertyType

> `const` **PropertyType**: `object`

Defines the supported data types for property values.

## Type Declaration

### String {#string}

> `readonly` **String**: `"String"` = `"String"`

Value is a string.

### BigInt {#bigint}

> `readonly` **BigInt**: `"BigInt"` = `"BigInt"`
